### 3. Mouse and trackpad — source defect fixed; physical delta gate open

The pass reproduced a real platform bug: `PlayerMouseLook` used `Input.mousePresent` to decide whether to lock and read a pointer on iOS. Unity 2022 documents that this property always returns false on iOS, so mouse/trackpad look could never activate.

The fix adds a narrow iPadOS bridge using Apple's `GCMouse` APIs:

- Raw mouse/trackpad deltas feed Daggerfall's existing mouse-look sensitivity and smoothing.
- Primary, secondary, and middle button state feeds the existing mouse action facade.
- Pointer lock is requested only while active gameplay wants mouse look.
- Touch input and Android pointer capture remain on their existing paths.
- `GameController.framework` is weak-linked by the deterministic Xcode postprocessor.

The rebuilt Simulator app logged a successful `GCMouse` connection, Unity export passed, and Xcode compiled the native bridge. The desktop automation layer does not emit physical `GCMouse` delta callbacks even when Simulator's Capture Pointer checkbox is active, so relative-look feel and button behavior cannot honestly be closed until the physical iPad test.
