# DaggerPad v0.1.0-preview.1

This is the first public DaggerPad IPA preview.

## Download

`DaggerPad-0.1.0-preview.1-unsigned.ipa`

SHA-256:
`d14544e950c8aee756822fbc4bc03f8922644173aa433bae5d7c09d0787de067`

The IPA is unsigned. Re-sign it with your own Apple ID and a compatible
provisioning profile before sideloading it onto an iPad running iPadOS 15 or
later.

## Verified

- ZIP integrity, arm64 architecture, `com.chrissotraidis.daggerpad` identity,
  version `0.1.0` build `1`, and iOS 15 minimum.
- No embedded signature, provisioning profile, Daggerfall game data, saves, or
  temporary input-trace instrumentation.
- Project license and third-party notices included inside the app bundle.
- The exact downloaded-form payload was extracted, re-signed locally, strictly
  verified, installed in place, and launched on a 12.9-inch M2 iPad Pro.
- The existing 36-file save tree was byte-for-byte unchanged after the update.

## Important

DaggerPad does not include Daggerfall. Supply your own legally obtained game
files through the in-app Files import. This preview is not an App Store or
TestFlight release, and broader physical-input, thermal, and long-session
acceptance remains open.
