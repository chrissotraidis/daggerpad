# DaggerPad v0.1.0-preview.2

This preview sizes the game from its own window on iPad and lets touch controls step aside for a controller, with a way to bring them back.

## Download

`DaggerPad-0.1.0-preview.2-unsigned.ipa`

The IPA is unsigned. Re-sign it with your own Apple ID and a compatible provisioning profile before sideloading it onto an iPad running iPadOS 15 or later. Install it over preview.1 with the same Apple ID to keep your imported files and saves.

## Fixed

- **Game window and external displays:** on iOS the game read its screen size from the display's current resolution. It now uses the size of the view it is drawn in, so the picture and touch input match the game's window in Split View, Stage Manager or on another display, such as a TV.
- **Touch controls with a controller:** while a controller is connected, the gameplay touch controls now step aside, leaving only **PAUSE** and the **MORE** button. While they are hidden, MORE reads **SHOW**: tapping it brings the controls back with the controller still connected and turns auto-hide off until you switch it on again. **Controls → Joystick** has a saved **Auto-hide with Controller** checkbox (on by default) that applies at once.

## Verified

- The IPA was built from the tagged source with Unity 2022.3.62f3 and packaged with `scripts/package-ios-ipa.sh`, which checks the ZIP, bundle identity, version, architecture, iOS floor, notices, and the exclusion of game data and trace instrumentation.
- **Physical TV and controller acceptance is pending:** these changes have not yet been tried on an external display or with a physical controller.

## Important

DaggerPad does not include Daggerfall. Supply your own legally obtained game files through the in-app Files import. This preview is not an App Store or TestFlight release.
